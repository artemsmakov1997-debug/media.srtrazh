# МЕДИА.СТРАЖ — предпросмотр, вариант 3

Предпросмотр учитывает выбор владельца: **сохранены исходные шапка, расположение
элементов и две большие кнопки режимов**. Из первого варианта оставлены графитовая
палитра, сворачиваемый фильтр и оформление карточек на телефоне. Дата и время
публикации теперь находятся в правом верхнем углу карточки: светлый текст на
сдержанной циановой подложке, без видимой подписи «Дата публикации».

Рабочие `index.html`, `analysis.html`, остальные страницы, их CSS/JS и Python-анализатор
не изменены. Изменения находятся только в папке предпросмотра и её проверках.

## Открыть интерактивное сравнение

1. [Откройте ветку в Codespaces](https://codespaces.new/artemsmakov1997-debug/media.srtrazh?ref=design%2Fanalysis-preview-v1).
   Ветка — `design/analysis-preview-v1`. Если Codespace уже открыт в этой ветке,
   сохраните свои изменения и выполните `git pull --ff-only` для получения актуального варианта.
2. В терминале из корня проекта:

   ```sh
   python3 design-preview/serve.py --bind 0.0.0.0 --port 8000
   ```

3. **Порты → 8000 → Открыть в браузере**. Порт можно оставить приватным.
4. Вверху — **До**, **После**, **Рядом**, **Телефон**. Для полноразмерного интерфейса
   нажмите **Открыть отдельно**. При необходимости обновите уже открытую страницу.

Свой сервер не нужен. При первом запуске существующий код проекта может загрузить
закреплённый Pyodide с проверкой SHA-512 архива и контрольных сумм файлов.
Установщики, hooks и скрипты Skills не используются.

## Что оставлено и что возвращено

| Элемент | Текущий вариант |
|---|---|
| Шапка и возврат к рейтингу | Исходная разметка, размеры, шрифты и расположение |
| «Автоматический анализ» / «Самостоятельная проверка» | Исходные большие кнопки: рядом на десктопе, друг под другом на телефоне |
| Масштаб и типографика | Исходные значения, включая существующее поведение desktop zoom |
| Цвета | Спокойные графитовые поверхности из первого предпросмотра; общий фон и циан сохранены |
| Фильтры | На десктопе исходное расположение; на телефоне сворачиваются, показывают выбранные условия, есть сброс |
| Карточки на телефоне | Плоские поверхности, скругления и удобные зоны действий из первого предпросмотра |
| Дата и время публикации | Справа сверху, заметнее обычных метаданных; значение, секунды и МСК сохранены |
| Ручной анализ | Исходная форма и её расположение; подсветка, пояснения и JSON сохранены |
| Дополнительный заголовок, боковая колонка и новый футер | Убраны |
| Новые строки статуса/охвата и выдача по 12 | Убраны; восстановлен исходный полный список |

`after.html` снова построен на копии оригинальной страницы: вне блока фильтров
разметка совпадает с `before.html`. Новый CSS меняет палитру и мобильные блоки,
новый JS отвечает за сворачивание фильтров, сброс и перенос уже отформатированной даты
в шапку карточки. Исходные скрипты режимов,
обработки публикаций и ручного анализа используются без изменений.

## Данные и проверки

Обе версии используют одну закреплённую публичную подборку: **100 публикаций**,
обновление **23 октября 2026, 23:58:03 МСК**, `rules-0.8.2`. Это данные для честного
сравнения оформления, а не текущая обновляемая лента.

База сбора, закрытый корпус и пользовательский ввод не включены. Шрифты с кириллицей
обслуживаются локально, с лицензиями OFL. Ручной текст не отправляется по сети.

Браузерная проверка сравнивает разметку, размеры, координаты и шрифты исходной шапки
и двух кнопок с новым вариантом на **девяти ширинах от 320 до 1440 px**; на десктопе
также сравнивается геометрия исходных фильтров. Дополнительно
проверяются фильтры/сброс, полный список, отсутствие горизонтального переполнения,
разбор публикации и возврат фокуса, точное совпадение ручного JSON с Python,
редактирование, очистка, пояснение при касании и обе обязательные оговорки.
Проверяется сохранение всех исходных значений дат, отсутствие наложения на источник
и заголовок, а также случаи без даты и с длинным названием/правовыми отметками при 320 px.

[Измерения и результаты](screens/checks.json). Проверка выполняется в Chromium;
физические телефоны и Safari пока не проверялись. GitHub Actions запускает также
287 тестов приложения и существующий полный браузерный набор с Python/Wasm-проверками.
Новый workflow ничего не развёртывает; `main` не изменяется.

Для повторной проверки:

```sh
python3 -m unittest discover -s tests -q
python3 -m media_strazh prepare-browser
python3 design-preview/check_preview.py --output /tmp/design-preview-checks
```

Браузерной проверке нужны Playwright и Chromium. Сервер предпросмотра использует
стандартный Python. Merge в main не выполнялся.
