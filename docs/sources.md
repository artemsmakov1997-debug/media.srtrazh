# Реестр сайтов и официальных Telegram-каналов

Единственный источник настроек — `media_strazh/sources.py`. Он используется
сборщиком, CLI, API и генератором публичного JSON. Страница `analysis.html`
строит список изданий по этому JSON; фильтры издания и площадки работают вместе.
Одна редакция объединяет две независимые ленты: сайт и официальный канал.
Пункт «Другие источники» не является конкретной лентой и не запускает сбор
произвольных сайтов.

```sh
python3 -m media_strazh sources
python3 -m media_strazh collect --source kommersant --limit 2
python3 -m media_strazh collect --source rt_telegram --limit 2
```

Если заданная лента отвечает 404 или не содержит корректной RSS/Atom, сборщик
делает одну ограниченную попытку найти официальную ленту по `rel="alternate"`

сторонний RSS-агрегатор не подставляется.

Основной текст извлекается из относящегося к странице `NewsArticle.articleBody`
или блока редакционного текста. RSS-анонс, страница входа, платная заглушка
и весь текст страницы с навигацией не заменяют статью. Новую вёрстку необходимо
сверять с оригиналом: успешное извлечение текста не доказывает его полноту.

## Telegram

Пользователь выбрал официальные каналы этих изданий. В реестре есть по одной
записи `<ID>_telegram` для каждого. Адрес подтверждается ссылкой самой редакции,
а не совпадением названия или количеством подписчиков.

На 11 октября 2026 года в этой облачной среде подтверждены ссылки:

| ID | Канал | Основание |
| --- | --- | --- |
| `rt_telegram` | `https://t.me/rt_russian` | [Главная RT](https://russian.rt.com/) содержит ссылку `telegram.me/rt_russian` |
| `ria_telegram` | `https://t.me/rian_ru` | [Главная РИА](https://ria.ru/) содержит ссылку `tgclick.com/rian_ru` |
| `interfax_telegram` | `https://t.me/interfaxonline` | Социальные ссылки [Интерфакса](https://www.interfax.ru/) |
| `meduza_telegram` | `https://t.me/meduzalive` | Подвал [Медузы](https://meduza.io/) |
| `novayagazeta_telegram` | `https://t.me/novaya_europe` | Подвал [Новой газеты Европы](https://novayagazeta.eu/) |
| `currenttime_telegram` | `https://t.me/currenttime` | Социальные ссылки [Настоящего Времени](https://www.currenttime.tv/) |
| `dw_telegram` | `https://t.me/dwglavnoe` | Социальные ссылки [DW на русском](https://www.dw.com/ru/) |
| `bbc_telegram` | `https://t.me/bbcrussian` | Блок «Подписывайтесь на наши соцсети» в [статье BBC](https://www.bbc.com/russian/articles/cm20v4zgr374o) |

Остальные восемь адресов в исходной конфигурации пока оставлены пустыми.
При сборе каждый из них проверяется автоматически: сборщик читает официальный
сайт и ищет единственную ссылку Telegram в шапке, подвале или блоке социальных
сетей. Ссылки внутри статей не служат подтверждением. Если подходящих адресов
несколько или ни одного, сохраняется явная ошибка с запросом уточнения.
Подтверждённый адрес сохраняется в состоянии источника для следующих циклов.

Неподтверждённые адреса не подставлены из предположений. Подтверждение адреса
канала отдельно от проверки доступности публичной ленты. Например, официальный
канал RT перенаправляет веб-ленту на страницу канала без сообщений, поэтому
наличие его адреса не означает успешного получения постов.

После разрешения доменов выполнить `collect --source <ID>_telegram` и сверить
полученный адрес и текст с оригиналом. Если сайт не даёт однозначного ответа,
подтверждённое имя можно закрепить в `OFFICIAL_CHANNELS`. Тесты парсера
проверяют обработку разметки и сохранение результата;
они не заменяют живую проверку канала.

Сбор читает открытую веб-ленту `https://t.me/s/<канал>` с соблюдением `robots.txt`.
Сохраняется текст каждого поста или подпись к медиа, его дата и постоянная ссылка.
Короткий текст допустим: Telegram-пост не обязан иметь длину газетной статьи.
Медиаданные без текста, недоступные сообщения, закрытые каналы и распознавание
изображений/аудио не входят в этот этап. Ограниченный срез открытой ленты
не гарантирует получение всех сообщений между запусками.

## Проверка в облаке и на GitHub

11 октября 2026 года выполнен живой цикл по всем 32 записям с лимитом двух
публикаций на ленту, а затем отдельная проверка исправленного адаптера BBC
и каналов BBC/Новой газеты Европы. В локальной проверочной базе сохранены
40 реальных текстов с анализом. Получение текста подтверждено для девяти сайтов
и семи каналов. Это проверка доступности и извлечения, а не независимая оценка
точности обнаружения приёмов.

| Издание | Сайт: полный текст | Telegram: текст поста |
| --- | --- | --- |
| RT | Получен | Адрес подтверждён; публичная веб-лента перенаправляет на страницу без постов |
| ТАСС | RSS доступна; `robots.txt` отвечает 403 | Адрес ещё не подтверждён |
| РИА Новости | Получен | Получен |
| Интерфакс | Получен | Получен |
| Коммерсантъ | Загрузка запрещена `robots.txt` | Адрес ещё не подтверждён |
| Ведомости | Получен | Адрес ещё не подтверждён |
| РБК | Страницы отвечают 401 | Адрес ещё не подтверждён |
| Известия | RSS отвечает 403 | Адрес ещё не подтверждён |
| Российская газета | RSS доступна; `robots.txt` отвечает 403 | Адрес ещё не подтверждён |
| Лента.ру | Загрузка запрещена `robots.txt` | Адрес ещё не подтверждён |
| Медуза | Получен | Получен |

| DW на русском | Получен | Получен |

Статус относится к ограниченной выборке и моменту проверки. Сайты меняют
вёрстку и правила доступа. Сборщик не отключает проверку сертификатов,
не обходит ограничения `robots.txt` и не извлекает закрытые платные тексты.
Проверочная SQLite-база, исходные HTML и полный корпус исключены из Git.

Доменный список облачной среды отдельный от сети исполнителя GitHub Actions.
Успех или блокировка в одном месте не доказывают такой же результат в другом.
Дополнительные домены новых СМИ, официальных RSS и Telegram сохранены в
черновике настройки среды с сохранением прежних разрешений. Чтобы применить
этот черновик, сохраните и опубликуйте среду в её настройках.

Состояние каждого сайта и канала можно увидеть в блоке «Состояние сбора» на
странице анализа. Отсутствие данных, отказ доступа и отсутствие настройки
не означают, что в публикациях нет манипулятивных приёмов.
