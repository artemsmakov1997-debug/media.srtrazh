# Словарь триггеров с автоматическими формами (`rules-0.18.0`, `lexicon-1.0`)

Модуль `media_strazh/lexicon.py` дополняет ручные правила `rules.py`. Каждое слово
записывается **один раз** с типом склонения, а программа сама строит:

- все падежи и оба числа (`враг → врага, врагу, врагом, враге, враги, врагов, врагам, врагами, врагах`);
- варианты «ё/е» (`живодёр` = `живодер`);
- составные слова с дефисом, пробелом или слитно, включая соединительное «о»
  (`укронацист`, `укро-нацист`, `укро нацист`, `русофашист`);
- сочетания «определение × слово» с одним словом между ними
  (`кровавый режим`, `кровавого киевского режима`, `преступная хунта`);
- обратные сочетания «слово + родительный падеж» (`режим убийц`, `банда террористов`).

Словарь работает тем же движком на сервере и в браузере (Pyodide). Ручные правила
проверяются раньше: если они уже нашли тот же фрагмент, словарь его не дублирует.
Статусы цитаты, отрицания и обсуждения слова назначаются как обычно.

## Решения владельца (6 ноября 2026)

- Все слова словаря относятся к **категориям манипуляций**, а не к информационному слою,
  и учитываются в рейтинге.
- Ярлыки обеих сторон добавляются **симметрично** («рашисты» и «укронацисты»,
  «орки» и «бандеровцы», «кацапы» и «хохлы»).
- Ограничения по контексту и минимальная выборка — следующий этап.

## Область действия

| Область | Когда срабатывает | Примеры |
| --- | --- | --- |
| `any` | всегда, кроме явных омонимов (`guard`) | хунта, рашист, укронацист, пыточная, силовые структуры |
| `public` | если в пределах 250 знаков есть публичный участник: страна, власть, армия, ВСУ, Кремль, город конфликта и т.п. | враг, убийца, террорист, укроп, нелюди |

Полиция, суды и прокуратура **не** считаются публичным контекстом намеренно:
в уголовной хронике «убийца задержан», «суд приговорил убийцу» — буквальное значение.

Защита от омонимов: косатка/орка и Толкин для «орков»; рецепты для «укропа» и
«мясорубки»; история Второй мировой для «нацистов» и «концлагеря»; зоопарк для «зверей»;
топливо для «биомассы». Кликбейт ищется только в заголовке (прежнее решение проекта).

### Преувеличение (`exaggeration`, `public`)
тотальный, беспрецедентный, небывалый, катастрофический, колоссальный, сокрушительный,
невиданный, неслыханный, грандиозный, феноменальный; «весь мир против/осуждает»,
«полностью уничтожен», «абсолютно все/никто».

### Обобщение (`generalization`)
«все/каждый/любой» + группа (мигранты, украинцы, русские, либералы, чиновники, журналисты…);
«группа + всегда / никогда не / по природе»; «у них в крови/в генах».

### Размытый источник (`vague_source`)
«источник, знакомый с ситуацией / близкий к / в правительстве», «осведомлённый источник»,
«собеседник издания», «по информации источников», «как стало известно», «по слухам»,
«в сети пишут», «западные СМИ пишут», инсайдер.

### Ссылка на авторитет (`appeal_to_authority`)
«британские/американские/… учёные доказали», «по мнению ведущих экспертов»,
«эксперты единодушны», «даже на Западе признают».

### Кликбейт (`clickbait`, только заголовок)
шок, шокирующий, сенсация, сенсационный, скандальный, «вы не поверите», «никто не ожидал»,
«вот что скрывают», «всплыла правда», «взорвал сеть», «о чём молчат».

### Упрощение (`oversimplification`, `public`)
«во всём виноват(ы)», «виноват Запад/Кремль/мигранты…», происки, «заговор Запада/элит»,
цветная революция, «другого пути нет», «третьего не дано».

## Как добавить слово

```python
# в нужную группу GROUPS внутри lexicon.py
words(("палач", "m"), ("карател", "m_soft"), ("бандеров", "m_ets"), ("вырод", "m_ok"),
      ("хунт", "f"), ("русн", "f_ya"), ("мраз", "f_soft"), ("правительств", "n"), ("пыточн", "adj"))
```

| Класс | Образец | Как указать основу |
| --- | --- | --- |
| `m` | враг, рашист | `("враг", "m")` |
| `m_soft` | каратель, москаль | `("карател", "m_soft")` |
| `m_ets` | бандеровец | `("бандеров", "m_ets")` |
| `m_ok` | выродок, застенок | `("вырод", "m_ok")` |
| `f` | хунта, банда | `("хунт", "f")` |
| `f_ya` | русня, армия | `("русн", "f_ya")` |
| `f_soft` | мразь, власть | `("мраз", "f_soft")` |
| `n` | государство | `("государств", "n")` |
| `adj` | пыточный, кровавый | `("пыточн", "adj")` |
| `raw` | любое регулярное выражение | `(r"хох(?:ол|ла|лы)", "raw")` |

После изменения: `python3 -m unittest discover -s tests`, затем поднять `VERSION`
в `analysis.py`, чтобы сохранённые публикации пересчитались.

## Отчёт по корпусу: влияние и кандидаты

```sh
python3 -m media_strazh lexicon-report --db data/media-strazh.sqlite3 --output exports/lexicon-report
```

В GitHub: **Actions → Collect news and publish analysis → Run workflow →
lexicon_report**. Из ветки, отличной от `main`, база только читается, новый сбор
не выполняется, сайт не публикуется. Результат — артефакт `lexicon-report-…`:

- `publishers.csv` — доля публикаций с маркерами по каждому СМИ **до** (без словаря) и **после**;
- `review-sample.csv` — 200 случайных срабатываний словаря с предложением и ссылкой для ручной проверки точности;
- `candidates-productive.csv` — ещё не известные слова, построенные как ярлыки (укро…, …изм, страна-…);
- `candidates-near-triggers.csv` — слова, которые чаще обычного стоят рядом с уже найденными маркерами.

Кандидаты автоматически **не добавляются**: их проверяет человек.

## Ограничения

Словарь находит все формы перечисленных слов и их сочетаний, но не перефразировки
и новые выражения, которых в нём нет. Их помогает искать отчёт по корпусу, а полностью
закрыть может только модель (этап 2 в `algorithm.md`). Точность словаря на реальных
публикациях ещё не измерена: используйте `review-sample.csv` и проверочный корпус.
