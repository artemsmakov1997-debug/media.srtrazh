# Разделы PRO

Четыре вкладки `/analysis/`: похожие заголовки, история сохранённых правок,
автоматический анализ и самостоятельная проверка. Существующий анализ сохранён.

Сборка публикует `data/pro.json` из сохранённых публикаций SQLite:
до восьми групп разных изданий и до двадцати публикаций с правками.
Группировка требует минимум три общих значимых слова, Jaccard ≥ 0.4,
разницу дат публикации не более суток, совпадение чисел и разные publisher ID.
Кандидаты отбираются из 4000 последних заголовков по темам войны/безопасности,
санкций/международных решений, прав/свобод и выборов/власти. Имена политиков
сами по себе не задают тему. Сравниваются упрощённо нормализованные слова;
требуются минимум две содержательные лексические разницы. Перестановки слов
и близкие падежные формы не заполняют раздел.
Это кандидаты на общий сюжет: событие необходимо сверить по источникам.
Подсвечены отличающиеся формулировки и признаки действующего анализатора
в заголовках. Для распознанных признаков используются его реальные пояснения;
остальные различия сопровождаются пояснением о сопоставлении формулировок.
Наличие выделения не доказывает манипуляцию.

История сначала выбирает статьи с несколькими версиями по всему корпусу
(до 20000 записей версий), затем сравнивает соседние сохранённые версии одной статьи с одинаковой
версией экстрактора. Изменение экстрактора не объявляется редакторской правкой.
Сохраняются последние пять пар различий. Время — первое сохранение версии
сборщиком; точный момент и причина правки неизвестны. Между обходами возможны
не замеченные изменения. Публично выводятся ограниченные фрагменты вокруг
первого изменения, а не полный частный корпус. Персональные причины правок
не устанавливаются. Если менялись и заголовок, и текст, оба поля доступны
в истории и фильтрах. Для каждого поля показан фрагмент вокруг первого изменения;
изменения после длинного неизменного начала также учитываются. Нет данных — пустое состояние; нет доступа — повтор загрузки.

Публичный продукт «Бизнес», его адреса, ресурсы, меню и JSON исключены из сборки.
Служебные функции прежней аналитики сохранены для совместимости хранения и тестов;
они не создают публичных страниц или API этого продукта.

Проверки: `test_pro.py`, `test_publishing.py`, `test_pretty_urls.py`,
`browser_pro_check.py` внутри полного браузерного набора. Проверяются ширины
375, 720 и 1280, все вкладки, клавиатура, фильтры, изменения и навигация.

## Проверка корпуса 21 ноября 2026

Read-only запуск `pro_audit` обнаружил 7 различий заголовков и 83 различия текстов
при одинаковой версии экстрактора. После исключения технических пересылок и форматирования выборка вывела
20 карточек, из них 15 с фиксациями за последнюю неделю, и 8 политических сравнений. Это наблюдаемые различия, а не
подтверждение авторства/намерения редакции. Заголовки о приговоре Марии Бонцлер
и о переговорах по НАТО/Донбассу проверены как реальные кандидаты в аудите.
Глобальное ограничение последних 1000 строк раньше скрывало старые версии
за свежими одноверсионными статьями. Переходы между разными экстракторами
по-прежнему исключаются. При нехватке материала согласована альтернатива
«Карта приёмов»; в проверенном корпусе материала для истории достаточно.

PRO во всех публичных меню — прямая ссылка `/analysis/`, без выбора продукта.
Зачёркнутая общая шапка сравнения удалена; названия конкретных сюжетов сохранены.

Смена имени переславшего Telegram-канала в служебной строке `Forwarded from`
и изменения только в пробелах/переносах не считаются правками публикации.
При содержательном изменении сравнивается текст без служебной атрибуции.
